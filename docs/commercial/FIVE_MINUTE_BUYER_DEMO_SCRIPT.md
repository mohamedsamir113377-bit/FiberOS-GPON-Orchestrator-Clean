# FiberOS R14.1 — 5-Minute Buyer Demo Script

## Recording standard

Record at 1080p or higher, browser chrome hidden, cursor visible only when clicking, and use the bilingual buyer demo with **English as the opening language**. Do not display secrets, private URLs, real customer data, or production credentials.

## 00:00–00:25 — Opening / credibility

Open the buyer demo and show the source-bound status strip.

Say:

> "This is a source-bound operational demonstration. The scenario is intentionally simulated; live production evidence remains a separate buyer-side verification boundary."

Keep the buyer demo in English so the technical flow remains consistent and presentation-ready.

## 00:25–01:25 — Incident War Room

Open **War Room**.

1. Start at the incident picture.
2. Click **Advance Lifecycle** through TRIAGE → IMPACT → DISPATCH.
3. Open the event log.
4. Highlight the distinction between simulated impact and live telemetry.

Key message:

> "The value is the connected operational state: incident, topology, impact, dispatch, evidence, and closure — with authority boundaries exposed."

## 01:25–02:05 — Digital Twin / GIS

Open **Digital Twin + GIS**.

1. Show the modeled network path.
2. Inject a controlled demo fault.
3. Run impact analysis.
4. Inspect the asset metadata and route surfaces.

Key message:

> "The browser can inspect the modeled network and call documented API surfaces. It does not fabricate live map telemetry."

## 02:05–02:55 — Optical engineering mathematics

Open **Optical Engineering**.

1. Show OTDR distance calculation.
2. Change the time input and recalculate.
3. Show backscatter attenuation.
4. Show optical link budget / Rx margin.
5. Optionally paste real decoded points into trace regression.

Key message:

> "These results are deterministic calculations from explicit inputs. Calculated output is kept separate from instrument evidence."

## 02:55–03:40 — Field operations

Open **Field Operations**.

1. Show ranked teams.
2. Click an assignment action.
3. Show the evidence checklist.
4. Open the closure-gate preview.

Key message:

> "Field closure is not just a UI button. The source distinguishes identity, tenant scope, evidence, idempotency, and database authority."

## 03:40–04:20 — Contact center + intelligence

Open **Contact Center** and advance the simulated call state.

Then show **Intelligence + AI** as advisory-only surfaces.

Key message:

> "Telephony and intelligence surfaces are explicit about provider/runtime dependencies and do not pretend that a local browser simulation is a live carrier connection."

## 04:20–04:50 — Security / assurance

Open **Security + Assurance**.

Show:

- OIDC/JWKS boundary;
- PostgreSQL/PostGIS + RLS boundary;
- Production Hold;
- rate-limit scope;
- buyer attestation requirement;
- fail-closed examples.

Key message:

> "The package is strongest when it shows what it refuses to claim. Static source evidence is not relabeled as customer production certification."

## 04:50–05:00 — Close / commercial handoff

Show the commercial package summary.

Say:

> "The proposed commercial package is USD 3,500 reference list price with 14 calendar days of technical support. White-label deployment and reseller use are documented; source redistribution and downstream master-reseller rights require explicit written agreement."

End on the buyer quickstart / support documentation, not on a claim of production readiness.

## Recording checklist

- English opened by default.
- Arabic selector demonstrated.
- All simulated data visibly labeled.
- No credentials or private production endpoints shown.
- No statement that the browser demo proves live PostgreSQL/RLS/OIDC.
- No claim that 114 locale files equal 114 completed translations.
- No revenue/payback guarantee.
