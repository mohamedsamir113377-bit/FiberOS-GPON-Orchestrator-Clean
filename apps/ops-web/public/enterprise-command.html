FTTH Engineering & Acceptance Assurance

Handbook-derived · truth-bound

Engineering control chain derived from the FTTH Handbook Edition 7 (2016) and reconciled against executable FiberOS surfaces. This panel does not invent live measurements, standards limits, instrument connectivity, or acceptance results.

Build → Accept

Survey → Design → Permit → Material → Civil → Duct → Cable → Splicing → Testing → QC → Acceptance → Drop → Activation

The current FTTH construction kernel already models this lifecycle and stage evidence requirements.

Optical Evidence

OTDR traces · insertion loss · Rx power · splice evidence · geo/evidence binding

Server-side optical mathematics and append-only measurement sources are present; instrument calibration provenance is not yet a first-class persisted entity.

ODN Digital Twin

Duct segments · cable segments · splices · ODN connections · construction evidence

These are database-backed structures and should remain the source of truth for route/as-built state.

Missing High-Value Controls

Test Campaign record · connector clean/inspect cycle · calibration reference · bidirectional OTDR result · explicit as-built readiness

These are identified additions, not claimed implementations. Acceptance must remain fail-closed until each control has real storage and verification.

Design Profiles

P2MP/PON · Ethernet P2P · MDU · splitter placement · feeder/distribution/drop topology

Handbook v7 treats architecture choice as deployment-specific. legacy numeric limits must not become universal 2026 constants; vendor/standard profiles should supply them.

Operations & Maintenance

Segmented testing · fault localization · evidence-linked rework · maintenance access · topology-aware records

The website should expose the evidence chain from work package to measurement, QC, acceptance, and final network record.

Operational Map — Real Spatial Data

Network Assets + Active Incidents + Tracked Technicians + Open Ticket Locations. This is an operational layer complementing MVT/GeoJSON, not a basemap from an external provider.
